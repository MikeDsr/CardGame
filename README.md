# 🎴 聚会卡堂 · 掌上桌游合集

一个完全中文化的移动端桌游合集，内置五款经典游戏，支持**单机 AI 对战**与**多人在线联机**，零成本部署。

| 游戏 | 人数 | 玩法 |
|------|------|------|
| 🐺 狼人杀 | 6-12 人 | 夜晚行动 + 白天发言投票，预言家/女巫/猎人齐全 |
| 🏯 三国杀 | 4-8 人 | 身份场（主公/忠臣/反贼/内奸），经典八将技能 |
| 🌈 UNO | 2-6 人 | 完整规则：功能牌、变色、+4、UNO 喊叫 |
| 👑 斗地主 | 3 人 | 叫分抢地主、全牌型判定、炸弹翻倍、春天 |
| 🎩 大富翁 | 2-6 人 | 环游中国 36 格棋盘、买地盖楼、机会命运 |

## ✨ 特性

- **全中文**：界面、提示、AI 发言全部本地化
- **单机模式**：任意游戏可与 AI 机器人立即开玩，无需网络
- **在线联机**：4 位数房间号邀请好友；人数不足 AI 自动补位；**中途掉线由 AI 无缝接管**
- **音效动画**：Web Audio 实时合成音效（无音频素材文件）、发牌/掷骰/UNO 喊叫等动画
- **零安装**：手机浏览器直接玩，可「添加到主屏幕」当 App 用

## 🚀 快速开始

```bash
npm install
npm start
```

打开 `http://localhost:3000` 即可游玩（浏览器按 F12 切换手机视图体验最佳）。

> ⚠️ 不能直接双击 `index.html` 打开——浏览器禁止 file:// 协议加载 ES 模块，必须通过服务器（本地 npm start / 在线链接）访问。

## ☁️ 在线部署

**GitHub Pages（已配置，推送即自动部署）**
仓库自带 `.github/workflows/pages.yml`，推送 main 分支后自动发布 `public/` 到
`https://<用户名>.github.io/<仓库名>/`。纯静态：单机 AI 模式开箱即玩；
在线联机需在「⚙️ 联机设置」里填一个 `wss://` 服务器地址（如下方 Cloudflare 部署）。

**Cloudflare Workers（免费，静态 + 联机二合一，推荐）**
仓库已带 `worker.js` + `wrangler.jsonc`（Durable Object 房间中继 + 静态资源）：

```bash
npx wrangler login    # 浏览器登录 Cloudflare（免费账号即可）
npx wrangler deploy   # 完成！得到 https://juhui-katong.<你的子域>.workers.dev
```

该链接页面与联机服务器同域，打开即可单机 + 联机，无需任何设置。

## 🌐 联机方案（免费 / 低成本，无需海外支付）

**方案零：一键开服（推荐，免费公网链接）**

双击项目根目录的 **`一键开服.bat`**，脚本会自动：
1. 启动游戏服务器；
2. 通过 bore.pub 免费隧道生成公网链接（形如 `http://bore.pub:12345`）；
3. 同时显示局域网地址。

把公网链接发给朋友，任何地方的手机浏览器都能直接打开一起玩。
保持窗口开启即保持在线；每次重开端口会变，重新分享即可。

**方案一：局域网（完全免费，推荐聚会时用）**
1. 一位玩家在电脑上运行 `npm start`
2. 查看本机局域网 IP（Windows：`ipconfig`，如 `192.168.1.5`）
3. 其他人连接**同一 WiFi**，手机浏览器访问 `http://192.168.1.5:3000`
4. 房主「创建房间」，其他人凭 4 位房间号加入

**方案二：国内云服务器（长期在线，¥20-40/月起）**
1. 购买任意国内轻量云主机（支付宝/微信付款）
2. 安装 Node.js ≥ 18，上传本项目，`npm install && npm start`
3. 放行防火墙 3000 端口，所有人访问 `http://服务器IP:3000`

> 大厅「⚙️ 联机设置」可自定义 WebSocket 服务器地址（页面与服务器分离部署时使用）。

## 🏗️ 架构

```
server.js              # 静态文件 + WebSocket 房间中继（不含游戏逻辑）
public/
  index.html           # 单页应用入口
  css/style.css        # 全局样式
  js/main.js           # 大厅/房间/游戏运行时（房主权威 + AI 调度）
  js/core/util.js      # 工具（弹窗、扑克牌、彩带…）
  js/core/audio.js     # Web Audio 合成音效引擎
  js/core/net.js       # 在线房间网络层
  js/games/*.js        # 五款游戏（每款 = 引擎 + AI + 渲染，自带样式）
```

- **房主权威**：游戏引擎只在房主设备上运行，服务器仅做消息转发，因此单机/联机共用同一套逻辑；
- **游戏模块接口**：`createEngine(players, emit)` + `ai(view, act)` + `render(root, view, send, ctx)`，新增游戏只需新建一个文件并在 `main.js` 注册。
